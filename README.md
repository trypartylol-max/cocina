# Cocina

Inventario de cocina personal: qué hay en casa, qué vence, lista de compras (con "Flash"), qué cocinar y menú de la semana.

- **App:** https://trypartylol-max.github.io/cocina/ (se instala en el iPhone con "Añadir a pantalla de inicio").
- **Front-end:** este repo, servido por GitHub Pages desde `main`.
- **Backend:** Google Apps Script ("Cocina web") sobre una hoja de Google del dueño. Copia versionada en [`backend/`](backend/).
- **Login:** cuenta de Google vía Supabase (la misma sesión que SHAAH, mismo origen `trypartylol-max.github.io`).

Los datos viven en la hoja de Google del dueño, no en este repo.
